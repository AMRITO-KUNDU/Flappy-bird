# Flappy Bird Game

A modern implementation of the classic Flappy Bird game using HTML5 Canvas, CSS3, and JavaScript.

## Features

- Retro-style pixel art graphics
- Responsive design that works on both desktop and mobile devices
- Touch and keyboard controls
- Medal system based on score achievements
- High score tracking using localStorage
- Smooth animations and physics
- Mobile-optimized gameplay

## How to Play

1. Open `index.html` in a modern web browser
2. Click, tap, or press spacebar to make the bird flap
3. Navigate through pipes to score points
4. Try to beat your high score!

## Controls

- **Desktop**: Click or press Spacebar
- **Mobile**: Tap anywhere on the screen

## Medals

- Bronze Medal: Score 10 points
- Silver Medal: Score 20 points
- Gold Medal: Score 30 points
- Platinum Medal: Score 40 points

## Technical Details

- Uses HTML5 Canvas for rendering
- Implements pixel-perfect collision detection
- Optimized for mobile devices with touch controls
- Responsive design that adapts to different screen sizes
- Uses requestAnimationFrame for smooth animation
- Implements device pixel ratio scaling for sharp graphics

## Browser Support

Works on all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge
- Mobile browsers
